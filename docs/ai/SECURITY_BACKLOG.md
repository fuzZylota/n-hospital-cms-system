### F02 / A03 — user edit POST transaction boundary (2026-09-29)

`controllers/post/users/users.go:EditUser` uses `utilities.Orm.Pool.BeginTx` for this request only. `user_edit_transaction.go` locks actor and target `users` rows in UID order, reads the current active actor role and real target role/sid, applies the existing `user_edit_policy.go` allowlist, then checks active branch rows in sorted order.
